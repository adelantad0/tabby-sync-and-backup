## Обзор

`tabby-sync-and-backup` позволяет синхронизировать профили подключений, цветовые схемы и настройки Tabby между несколькими компьютерами, одновременно сохраняя локальные версионные снимки (бэкапы) для защиты от случайной потери конфигурации.

## Ключевые возможности

- **Движок мульти-девайсной синхронизации**: Архитектура Device-Per-File (`devices/<deviceId>.json`) с логическими часами Лампорта, хешами содержимого SHA-256 и 30-дневным окном надгробных меток (tombstones). Полностью исключает конфликты одновременной записи в облачных сервисах (iCloud, Dropbox, Syncthing, WebDAV).
- **Сквозное шифрование (E2EE)**: Аутентифицированное шифрование AES-256-GCM с деривацией ключа PBKDF2 (10 000 итераций). Нулевая утечка открытого текста на диске и в облачном хранилище.
- **Ротация эпох ключа (Key Epochs)**: Отслеживание смены мастер-пароля между устройствами с безопасной блокировкой синхронизации при несовпадении паролей.
- **Слияние без потери данных**: Параллельные офлайн-изменения автоматически разветвляются в безопасные дубликаты (`Профиль (Конфликт с устройства <Device>)`), сохраняя все данные подключения.
- **Автоматические Pre-Sync бэкапы**: Обязательное создание локального снимка конфигурации перед каждым слиянием.
- **Проверка подключения к хранилищу**: Измерение времени отклика (latency) и проверка доступности WebDAV и локальных папок в реальном времени.
- **Выборочная синхронизация**: Возможность выбирать синхронизацию профилей, папок, паролей (Vault) или тем, сохраняя пути к системным оболочкам и локальные горячие клавиши нетронутыми.
- **Полная мультиязычность (i18n)**: Встроенная поддержка английского, русского (Русский) и упрощённого китайского (简体中文) языков. Автоматически адаптируется под выбранный язык Tabby.

## Разделы настроек

В разделе **Настройки -> Синхронизация и бэкапы** доступны четыре основные вкладки:
1. **🔄 Синхронизация**: Выбор типа хранилища (WebDAV, локальная папка), настройка расписания, панель сохранения изменений и ручное управление синхронизацией.
2. **🛡️ Бэкапы**: Управление локальными (в папке Tabby) и облачными (`/backups`) резервными копиями, автоматическая ротация старых копий, создание снимков при запуске и восстановление в один клик.
3. **🔐 Безопасность**: Шифрование AES-256-GCM, проверка мастер-пароля, бейджи статуса шифрования бэкапов (`Открытый`, `Зашифрован (OK)`, `Зашифрован (другой ключ)`), пакетное перешифрование при смене пароля.
4. **ℹ️ О плагине**: Информация о версии, проверка обновлений, копирование диагностики и история релизов.

## Установка

### Через менеджер плагинов Tabby
1. Откройте **Настройки** Tabby (`Cmd + ,` или `Ctrl + ,`).
2. Перейдите во вкладку **Плагины** (Plugins).
3. Введите в поиске `tabby-sync-and-backup`.
4. Нажмите **Установить** и перезапустите Tabby.

### Ручная установка
Выполните в директории пользовательских плагинов Tabby:
```bash
npm install tabby-sync-and-backup
```

## Доступные команды

Команды доступны через палитру команд Tabby (**Command Palette**, `Cmd + Shift + P` / `Ctrl + Shift + P`):
- `Sync & Backup: Синхронизировать настройки`
- `Sync & Backup: Создать локальный бэкап`

Горячие клавиши можно переназначить в разделе **Настройки -> Горячие клавиши**.

## Разработка

```bash
# Клонирование репозитория
git clone https://github.com/adelantad0/tabby-sync-and-backup.git
cd tabby-sync-and-backup

# Установка зависимостей и сборка
npm install
npm run build

# Режим наблюдения для разработки
npm run watch
```

Симлинк для локального тестирования в Tabby:
```bash
# Пример для macOS
mkdir -p "$HOME/Library/Application Support/tabby/plugins/node_modules"
ln -sfn "$(pwd)" "$HOME/Library/Application Support/tabby/plugins/node_modules/tabby-sync-and-backup"
```
