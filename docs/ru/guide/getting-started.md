# Быстрый старт

Добро пожаловать в **Tabby Sync & Backup**! В этом руководстве вы узнаете, как установить плагин и настроить первую синхронизацию всего за 2 минуты.

---

## 1. Установка

Плагин можно установить прямо через графический интерфейс Tabby или вручную через консоль.

### Способ А: Через менеджер плагинов Tabby (Рекомендуется)

1. Откройте **Tabby**.
2. Перейдите в **Настройки** (`Cmd + ,` на macOS или `Ctrl + ,` на Windows/Linux).
3. В левой колонке выберите **Плагины** (Plugins).
4. В строке поиска введите `tabby-sync-and-backup`.
5. Нажмите кнопку **Установить** (Install).
6. Перезапустите Tabby по запросу программы.

### Способ Б: Ручная установка через npm

Перейдите в директорию плагинов пользователя Tabby и выполните:

```bash
npm install tabby-sync-and-backup
```

* **macOS:** `~/Library/Application Support/tabby/plugins`
* **Windows:** `%APPDATA%\tabby\plugins`
* **Linux:** `~/.config/tabby/plugins`

---

## 2. Где найти настройки плагина

После перезапуска в меню настроек Tabby появится новый раздел:

1. Откройте **Настройки** (`Cmd + ,` или `Ctrl + ,`).
2. В боковом меню выберите **Sync & Backup** (Синхронизация и бэкап).

Здесь доступны пять вкладок:
* **🔄 Синхронизация (Sync)**: выбор хранилища и ручной запуск синхронизации.
* **🛡️ Резервные копии (Backups)**: список локальных и удаленных снапшотов с кнопкой восстановления.
* **🔐 Безопасность (Security)**: настройка мастер-пароля для сквозного шифрования.
* **📜 История изменений (Changelog)**: список изменений в версиях плагина.
* **ℹ️ О программе (About)**: информация о версии и ссылки на поддержку.

---

## 3. Первый запуск: 3 простых шага

1. Откройте вкладку **Безопасность (Security)**.
2. Задайте надежный **Мастер-пароль** — он включит надежное сквозное шифрование.
3. Перейдите на вкладку **Синхронизация (Sync)**:
   * Выберите тип хранилища (например, *Локальная папка* для папки iCloud/Dropbox или *WebDAV*).
   * Укажите путь или URL сервера и нажмите **Проверить подключение** (Test Connection).
4. Нажмите **Сохранить настройки** (Save Settings).
5. Нажмите кнопку **Синхронизировать сейчас** (Sync Now). Готово!

---

## Команды палитры быстрого доступа

Вы можете запускать действия в любой момент без открытия окна настроек с помощью **Палитры команд** (`Cmd + Shift + P` / `Ctrl + Shift + P`):

* `Sync & Backup: Synchronize Settings` — мгновенная синхронизация.
* `Sync & Backup: Create Local Backup` — мгновенное создание резервной копии.

> [!TIP]
> Вы можете назначить свои удобные горячие клавиши для этих команд в разделе **Настройки -> Горячие клавиши (Hotkeys)**.
