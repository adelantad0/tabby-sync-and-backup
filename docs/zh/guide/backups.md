# 备份管理与恢复

即使同步体系足够健壮，意外仍然在所难免：误删主机、改错配色或操作系统崩溃。

**备份模块 (Backups)** 就是守护您配置安全的最终避风港。

---

## 1. 全自动快照触发机制

Tabby Sync & Backup 支持两种维度的无感自动化备份策略：

1. **同步前强制快照 (默认开启)**：  
   在任何云端拉取回来的新配置合并至 Tabby 前，系统会首先对当前配置执行一次本地快照。一旦发生任何不符合预期的变动，随时可以一键恢复。
2. **应用启动快照**：  
   在每次启动打开 Tabby 时自动生成历史节点，留存清晰的日常变更轨迹。

---

## 2. 存储配额与自动轮转清理

为避免无限制快照占用宝贵的磁盘或网盘配额：

* 您可以自定义 **快照最大保留数量**（默认为 `20` 份）。
* 系统采取先进先出 (FIFO) 策略自动淘汰最久远的旧快照，始终保留最新版本。

---

## 3. 一键还原操作指南

1. 打开 Tabby **设置 -> Sync & Backup -> 备份 (Backups)**。
2. 浏览快照列表，清晰列出：
   * 生成的确切时间戳。
   * 包含的服务器配置数与主题数。
   * 加密状态徽标（如 `已加密 (正常)`）。
3. 点击目标快照右侧的 **还原 (Restore)** 按钮。
4. Tabby 将在 1 秒内平滑重载为您所选的指定历史配置。

---

## 4. 换机迁移实操（1 分钟指南）

换购新电脑或重装操作系统后：

1. 安装 **Tabby** 及 `tabby-sync-and-backup` 插件。
2. 前往 **设置 -> Sync & Backup -> 安全 (Security)** 输入原有 **主密码**。
3. 切换至 **同步 (Sync)** 标签页，指向已存在的云端或 WebDAV 目录，点击 **保存设置**。
4. 点击 **立即同步 (Sync Now)**。
5. 几秒之内，所有服务器连接、分组目录与偏好配色瞬间完整呈现在新电脑上！
