# 安全与加密保证

终端配置往往涉及极高敏感级信息：生产服务器 IP 地址、登录用户名、SSH 专有私钥与认证口令。

**数据安全与隐私防护是 Tabby Sync & Backup 的立足基石。**

## 1. 密码学技术实现

### 认证加密机制 (AES-256-GCM)
* 选用现代密码学黄金标准：**伽罗瓦/计数器模式下的 AES-256 (AES-256-GCM)**。
* GCM 模式不仅提供严密的机密性，更提供**完整性认证保障**：即使云服务器提供商或第三方中间人篡改了加密密文中的任何单个字节，本地解密将直接报错并熔断，防止任何密文篡改注入攻击。

### 密钥拉伸强化 (PBKDF2)
* 用户主密码绝不会被直接用作加密密钥，而是经由 **PBKDF2 算法结合 10,000 轮循环哈希计算** 及独一无二的随机盐值推导而成。
* 即便他人获取了云端的加密镜像文件，也无法通过常规算力暴力破解。

## 2. 深度适配 Tabby Vault 密码库

Tabby 自带专门加密私钥和密码的 **Vault（保险库）**。

* 插件与 Tabby Vault 体系原生协同。
* 您可在设置中自主决策：是将保管库凭据同步至自己的设备，还是将凭证仅保留在单机，仅在云端同步基础外观与连接标签。

---

## 3. 密钥纪元追踪 (Key Epochs)

如果您在家庭电脑上更新了主密码，而办公电脑尚未更改，会导致旧密码覆盖新文件吗？

* 插件内置 **密钥纪元追踪 (Key Epochs)**。
* 若设备察觉云端数据已流转至更新的纪元版本，会**立即锁定写入并拒绝同步**，弹窗请求您输入新密码。
* 彻底规避因密码版本不一致引发的数据覆写悲剧。

## 4. 备份加密徽标说明

在 **安全 (Security)** 设置面板，每个备份文件均带有直观的安全状态徽标：

| 徽标状态 | 含义解释 | 处置建议 |
| :--- | :--- | :--- |
| <span style="color:#22c55e;font-weight:600">● 已加密 (正常)</span> | 已经由当前主密码安全加密。 | 无需操作，完全安全。 |
| <span style="color:#eab308;font-weight:600">● 其他密钥加密</span> | 由旧纪元密码或其他密码加密。 | 可使用「批量重加密」一键更新。 |
| <span style="color:#ef4444;font-weight:600">● 明文状态</span> | 早期未加密的本地历史快照。 | 建议设置主密码将其转为加密快照。 |

## 5. 安全操作最佳实践

1. **牢记您的主密码：** 由于端到端加密零知识特性，不存在「找回密码」功能。请务必妥善记录在个人密码管理器中。
2. **多端保持一致：** 确保挂载在同一存储路径下的所有电脑输入完全相同的加密主密码。
3. **WebDAV 建议：** 使用 WebDAV 时，始终启用 HTTPS 协议，并在网盘安全设置中创建独立的「应用专属访问密码」，切勿直接使用网盘主账户密码。
